# LUNEV ONE — Interactive Product Experience

Production v4 prototype for a fictional premium wireless headphone brand.

## Implemented
- Next.js App Router + TypeScript
- Persistent React Three Fiber canvas
- Desktop / tablet / mobile camera profiles
- Scroll-linked product storytelling
- Sound driver reveal
- Silence visual field
- Longevity replaceable-part reveal
- Explore mode with rotation, hotspots and reset
- Graphite / Natural / Warm Stone live material switching
- Mock Configure & Buy drawer + bag state
- Mobile-specific 3D scale/FOV/DPR and touch targets
- Reduced-motion and WebGL fallback paths
- Reproducible named-part GLB
- Asset/model/source validation scripts

## Run locally
```bash
npm install
npm run dev
```

## Release validation
```bash
npm run release:check
```

This repository is used for the LUNEV ONE portfolio project and Vercel deployment.
